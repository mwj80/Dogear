# P1-0 scaffold — how to add this to GitHub

Upload **the contents of this folder** to the **root of your existing repo**
(same level as PRODUCT_SPEC.md), not inside a nested `prod-web` folder.

You should end up with:

```
PRODUCT_SPEC.md
AGENTS.md
docs/
package.json
tsconfig.json
next.config.ts
src/app/page.tsx
src/app/layout.tsx
src/app/globals.css
.gitignore
.env.example
```

On github.com: Add file → Upload files → drop these files → Commit.

Do not upload `node_modules` (there isn’t one in this zip).

You cannot “run” the app from GoDaddy or from github.com yet.
P1-0 is only the project skeleton.
